1️⃣ Rational vs. Irrational

A rational number can be written as a fraction a/b (b ≠ 0). Its decimal either terminates or repeats. An irrational number cannot be written as a fraction — its decimal goes forever without repeating.
Examples: Rational: 3, -5, 1/2, 0.75, 0.333… Irrational: √2, √3, π, e.

Practice:

  1. Classify 4/9 as rational or irrational.
  2. Classify 0.121212… as rational or irrational.
  3. Classify √16 as rational or irrational.
  4. Classify √17 as rational or irrational.
  5. Classify π = 3.14159… as rational or irrational.
  6. Classify 0.101001000100001…

3️⃣ Estimating Irrational Square Roots

If a number is NOT a perfect square, its square root is irrational. Estimate by finding the two nearest perfect squares.
Example: √20. Nearest perfect squares: √16 = 4 and √25 = 5. Since 20 is closer to 16 than 25, √20 ≈ 4.5 (actually 4.47).

5️⃣ Converting Repeating Decimals to Fractions

A repeating decimal is rational. To convert, use algebra: let x = the decimal, multiply to shift the repeating part, subtract, solve.
The trick — align, subtract, solve. The infinite repeating tail is messy. If we make two copies of the number shifted so the tails line up, subtracting kills the tail and leaves clean algebra.

Example 1 — Convert 0.333… to a fraction:

  1. Name it: Let x = 0.333…
  2. Shift it: Multiply by 10 (one digit repeats).
    10x = 3.333…
  3. Subtract to kill the tail: 
       10x  =  3.333333…
 −   x  =  0.333333…
─────────────────────
    9x  =  3
    The identical .333… tails cancel perfectly.
  4. Solve: 9x = 3, so x = 3/9 = 1/3. ✓ (Check: 1 ÷ 3 = 0.333…)

Example 2 — Convert 0.121212… to a fraction (two digits repeating):

  1. Name it: Let x = 0.121212…
  2. Shift it: The repeating block "12" is two digits long, so multiply by 100 to slide the decimal two places right.
    100x = 12.121212…
  3. Subtract to kill the tail: 
      100x  =  12.121212…
 −   x  =   0.121212…
──────────────────────
   99x  =  12
    The identical .121212… tails cancel perfectly.
  4. Solve: 99x = 12, so x = 12/99 = 4/33 (divide top and bottom by 3). ✓ (Check: 4 ÷ 33 = 0.121212…)

Why 100 instead of 10? If you only multiplied by 10, you'd get 10x = 1.212121… with a .212121… tail — different from x's .121212… tail — and they wouldn't cancel. Always multiply by 10 raised to the length of the repeating block: 1 digit → 10, 2 digits → 100, 3 digits → 1000.

💡 Pattern: When one digit d repeats, the fraction is always d/9.
So 0.1̄ = 1/9, 0.4̄ = 4/9, 0.7̄ = 7/9, 0.8̄ = 8/9. If two digits repeat, the denominator is 99 (e.g. 0.27̄ = 27/99 = 3/11); three digits → 999.
