🎬 Streaming Showdown

Two streaming plans, different pricing — which one is smarter for how much you watch?

🎯 The Situation

Your family is picking a streaming plan for the month. You find two options:

One is unlimited for a flat monthly fee. The other has a lower base fee but charges per movie you watch.

Question: Which is cheaper depends on how many movies you plan to watch. Use y = mx + b to decide!
🎥 StreamAll — All-You-Can-Watch
  • Monthly cost: $12/month (flat rate — unlimited)
  • Per movie: $0 (already included)
Equation: try to figure it out ↓
🎞️ MovieMart — Pay As You Watch
  • Base cost: $5/month (just to be a member)
  • Per movie: $1 each
Equation: try to figure it out ↓

1️⃣ Set Up the Equations

Write each cost as y = mx + b, where y = total cost and x = number of movies watched.

🎥 StreamAll (Plan A)

$0 because it's unlimited!
flat monthly fee
Slope = 0 because your bill doesn't go up when you watch more movies. Watching 3, 30, or 300 movies costs the same $12/month.
A slope of 0 means the graph is a horizontal line.

🎞️ MovieMart (Plan B)

$ added for each movie
$ just to be a member

2️⃣ See the Graph

Watch the two lines appear as you enter the correct values. Where they cross is the break-even point.

🎯 The StreamAll line is flat (slope 0). MovieMart slopes upward as you watch more movies.

3️⃣ Find the Break-Even Point

Set the equations equal: how many movies until both plans cost the same?

Start:   12 = x + 5
Subtract 5 from both sides:   = x
So x = movies
x = 7 movies is the tipping point:
   StreamAll = $12 (always, no matter what)
   MovieMart = 1(7) + 5 = $12 ✓

So if you watch fewer than 7 movies, MovieMart is cheaper (you pay less base + a few movies).
If you watch more than 7, StreamAll wins (the flat $12 beats paying per movie).

4️⃣ Make a Recommendation

Ari only watches about 3 movies a month.

Ben watches 15 movies a month.

Cam watches exactly 7 movies a month.

  • Fewer than 7 movies → MovieMart wins (low base beats flat $12).
  • Exactly 7 movies → Tie — both cost $12.
  • More than 7 movies → StreamAll wins (unlimited beats paying per movie).

🎓 What You Learned

A flat rate plan is a horizontal line (slope 0, y-intercept = the flat price). A pay-per-use plan has a slope (the per-use cost) and often a small y-intercept (a base fee).

When comparing plans, the break-even point is where the lines cross. That number is the "pivot" that tells you which plan is smarter for your usage.
