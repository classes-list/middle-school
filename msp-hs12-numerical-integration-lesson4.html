📘 How It Works

Key idea: Average neighboring heights.

Trapezoidal rule: each piece is ½(left height + right height) × width. With equal widths: (Δx/2)[f(x₀) + 2f(x₁) + … + 2f(xₙ₋₁) + f(xₙ)].
