📘 How It Works

Key idea: a < 0 → maximum; a > 0 → minimum.

If a > 0 the parabola opens up and the vertex is a minimum; if a < 0 it opens down and the vertex is a maximum. The y-intercept is c (plug in x = 0).

👀 Watch Two Examples

✏️ Worked Example 1
Find the maximum value of y = −3x² − 24x − 57.
Answer: -9
✏️ Worked Example 2
What is the y-intercept of y = 3x² + 6x − 3?
Answer: -3
