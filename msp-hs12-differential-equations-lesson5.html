📘 How It Works

Key idea: y = y₀e^(kt).

dy/dt = ky gives y = y₀e^(kt). y₀ is the starting amount; k > 0 growth, k < 0 decay. Solve for k from a second data point using ln.

👀 Watch Two Examples

✏️ Worked Example 1
dy/dt = 0.1y with y(0) = 1000. Find y(18) (nearest tenth).
Answer: 6049.6
✏️ Worked Example 2
