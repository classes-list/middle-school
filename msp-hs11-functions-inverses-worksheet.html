1️⃣ Composition

Work from the inside out.

Practice:

  1. f(x) = 2x + 5 and g(x) = x² − 1. Find f(g(1)).

  3. f(x) = x − 5 and g(x) = x² + 2. Find f(g(-1)).

2️⃣ Inverse Functions

Swap x and y, then solve for y.

Practice:

  1. f(x) = 4x + 8. Find f⁻¹(7).
  2. f(x) = −2x + 6. Find f⁻¹(-7).
  3. f(x) = −2x − 4. Find f⁻¹(-6).
  4. f(x) = −2x + 5. Find f⁻¹(5).

3️⃣ Piecewise Functions

Pick the rule whose condition matches x.

Practice:

  1. f(x) = 3x + 3 if x < -1, and 0 − 2 if x ≥ -1. Find f(3).
  2. f(x) = 3x + 1 if x < 0, and −2x² + 3 if x ≥ 0. Find f(-4).
  3. f(x) = 3x − 1 if x < 2, and −3x² + 2 if x ≥ 2. Find f(-2).
  4. f(x) = x + 2 if x < -2, and −3x² − 1 if x ≥ -2. Find f(4).
—

Answer Key — Section 3

(1) -2 (2) -11 (3) -7 (4) -49

4️⃣ Even & Odd

Check f(−x).

Practice:

  1. Is f(x) = |x| + 1 even, odd, or neither?
  2. Is f(x) = sin x even, odd, or neither?
  3. Is f(x) = x⁴ − 3x² even, odd, or neither?
  4. Is f(x) = x² + x even, odd, or neither?
—

Answer Key — Section 4

(1) even (2) odd (3) even (4) neither
