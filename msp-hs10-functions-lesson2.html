📘 How It Works

Key idea: Plug the input in for every x.

f(x) notation is an instruction: “replace x with this number.” Put the input in parentheses everywhere x appears, then follow the order of operations. Be careful with negatives: (−3)² = 9.

👀 Watch Two Examples

✏️ Worked Example 1
f(x) = −4x² − 5x − 2. Find f(-3).
Answer: -23
✏️ Worked Example 2
f(x) = x² + x + 4. Find f(-4).
Answer: 16
