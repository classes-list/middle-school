📘 How It Works

Key idea: Use the piece on that side.

For a one-sided limit of a piecewise function, use the rule for the side you are approaching from: x → a⁻ uses the left piece, x → a⁺ the right piece.

👀 Watch Two Examples

✏️ Worked Example 1
f(x) = x − 2 for x < -2 and 2x − 4 for x ≥ -2. Find the limit as x → -2 from the left.
Answer: -4
✏️ Worked Example 2
f(x) = x + 5 for x < 3 and 2x − 3 for x ≥ 3. Find the limit as x → 3 from the left.
Answer: 8
