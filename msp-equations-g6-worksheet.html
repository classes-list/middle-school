1️⃣ What Is an Equation?

Two expressions with an EQUAL sign. Solve by finding the variable value.

Practice:

  1. x + 5 = 10. x?
  2. x − 3 = 7. x?
  3. 3x = 15. x?
  4. x/2 = 6. x?

Answer Key — Section 1

(1) x = 5 (2) x = 10 (3) x = 5 (4) x = 12

2️⃣ Inverse Operations

Do the OPPOSITE to both sides to undo the operation.
+ undoes − ; × undoes ÷ ; and vice versa.

Practice:

  1. x + 8 = 15
  2. x − 6 = 11
  3. 5x = 40
  4. x/3 = 8
  5. x + 12 = 12
  6. 4x = 0

Answer Key — Section 2

(1) x = 7 (2) x = 17 (3) x = 8 (4) x = 24 (5) x = 0 (6) x = 0

3️⃣ Word Problems

Translate to an equation, then solve.

Practice:

  1. A number plus 7 is 20. Find it.
  2. 5 times a number is 45. Find it.
  3. A number divided by 3 is 12. Find it.
  4. John spent $8, now has $12. How much before?

Answer Key — Section 3

(1) x+7=20, x=13 (2) 5x=45, x=9 (3) x/3=12, x=36 (4) x−8=12, x=20

4️⃣ Checking Solutions

Substitute your answer back into the equation to verify.

Practice:

  1. Solve x + 4 = 9. Check.
  2. Solve 6x = 42. Check.
  3. Solve x − 15 = 10. Check.

Answer Key — Section 4

(1) x = 5. Check: 5 + 4 = 9 ✓ (2) x = 7. Check: 6(7) = 42 ✓ (3) x = 25. Check: 25 - 15 = 10 ✓
