📘 How It Works

Key idea: Check the condition first, then use that rule.

A piecewise function has different rules for different x-values. Step 1: look at the conditions and decide which rule your x belongs to (watch < versus ≥ at the break point). Step 2: plug x into ONLY that rule.

👀 Watch Two Examples

✏️ Worked Example 1
f(x) = −3x + 5 if x < 3; f(x) = 2x² − 3 if x ≥ 3. Find f(1).
Answer: 2
✏️ Worked Example 2
f(x) = −3x − 2 if x < 2; f(x) = x² − 1 if x ≥ 2. Find f(3).
Answer: 8
