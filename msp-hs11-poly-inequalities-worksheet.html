1️⃣ Quadratic Inequalities

Factor, find the zeros, test between them.

Practice:

  1. Solve x² + 4x − 21 ≥ 0. The solution is x ≤ a or x ≥ b. Find a.
  2. Solve x² + 12x + 35 > 0. The solution is x < a or x > b. Find b.
  3. Solve x² + 6x + 5 ≤ 0. The solution is an interval from a to b. Find b.
  4. Solve x² − 7x − 8 > 0. The solution is x < a or x > b. Find b.
—

Answer Key — Section 1

2️⃣ Sign Charts

Count negative factors: even → +, odd → −.

Practice:

  1. For f(x) = (x + 6)x(x − 3), is f(5) positive or negative? (Use a sign chart — no need to multiply everything out.)
  2. How many integers x with −5 ≤ x ≤ 8 satisfy (x + 2)(x − 3)(x − 5) < 0?
  3. For f(x) = −(x + 3)(x − 4)(x − 6), is f(8) positive or negative? (Use a sign chart — no need to multiply everything out.)
  4. How many integers x with −6 ≤ x ≤ 7 satisfy (x + 3)x(x − 4) < 0?
—

Answer Key — Section 2

(1) positive (2) 4 (3) negative (4) 6

3️⃣ Rational Inequalities

Numerator and denominator zeros split the line; denominator zeros are open.

Practice:

  1. Solve (x + 4)/(x − 1) > 0. The solution is two rays: x beyond a on the left and beyond b on the right (a < b). Find a. (Note: x = 1 is never included.)
  2. Solve (x − 2)/(x − 4) ≥ 0. The solution is two rays: x beyond a on the left and beyond b on the right (a < b). Find a. (Note: x = 4 is never included.)
  3. Solve (x + 5)/(x + 2) < 0. The solution is an interval between a and b (a < b). Find a. (Note: x = −2 is never included.)
  4. Solve (x − 3)/(x − 4) < 0. The solution is an interval between a and b (a < b). Find b. (Note: x = 4 is never included.)
—

Answer Key — Section 3

(1) -4 (2) 2 (3) -5 (4) 4

4️⃣ Applications

Set up “height > value,” then solve.

Practice:

  2. A ball’s height is h(t) = −16t² + 160t. For how many seconds is the ball higher than 336 feet?
  3. A ball’s height is h(t) = −16t² + 96t. For how many seconds is the ball higher than 128 feet?
  4. A ball’s height is h(t) = −16t² + 128t. For how many seconds is the ball higher than 240 feet?
