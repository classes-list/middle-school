📘 How It Works

Key idea: Point + slope.

Tangent line at x = a: find the point (a, f(a)) and the slope m = f′(a). Then y − f(a) = m(x − a). Plug in any x to use the line.

👀 Watch Two Examples

✏️ Worked Example 1
Find the slope of the tangent line to y = −3x² + 3 at x = 2.
Answer: -12
✏️ Worked Example 2
Find the y-intercept of the tangent line to y = x² − x at x = 2.
Answer: -4
