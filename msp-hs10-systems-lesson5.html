📘 How It Works

Key idea: Test the point in the inequality.

To check if a point is a solution to a system of inequalities, substitute it into EVERY inequality. It is a solution only if all of them are true. On a graph, the solution region is where all the shadings overlap.

👀 Watch Two Examples

✏️ Worked Example 1
Is the point (-2, 1) a solution of y ≤ x − 2? (yes or no)
Answer: no
✏️ Worked Example 2
Is the point (2, -5) a solution of y ≥ −3x + 3? (yes or no)
Answer: no
