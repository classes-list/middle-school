📘 How It Works

Key idea: Make one variable’s coefficients opposites and add.

Elimination: line up the equations, multiply one (or both) so a variable has opposite coefficients, then add the equations — that variable disappears. Solve for the remaining variable, then substitute back to find the other.

👀 Watch Two Examples

✏️ Worked Example 1
Solve the system 3x − 4y = -24 and 2x + 3y = 18. What is x?
Answer: 0
✏️ Worked Example 2
Solve the system 3x − 2y = -7 and 3x + 3y = -12. What is y?
Answer: -1
