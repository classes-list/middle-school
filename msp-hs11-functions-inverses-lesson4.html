📘 How It Works

Key idea: Pick the rule whose condition matches x.

A piecewise function lists rules with conditions. Read the conditions first, pick the one your x satisfies (watch the endpoints: < vs ≤), and evaluate only that rule.

👀 Watch Two Examples

✏️ Worked Example 1
f(x) = 3x − 4 if x < -2, and 0 + 1 if x ≥ -2. Find f(5).
Answer: 1
✏️ Worked Example 2
f(x) = x − 3 if x < 3, and −3x² − 4 if x ≥ 3. Find f(-3).
Answer: -6
