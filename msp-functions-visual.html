🔁 Functions — Input, Rule, Output

A function is a machine: feed it a number, follow the rule, out comes exactly ONE answer.

The function machine: each input x gets sent through the rule (like 2x + 3), and out comes exactly one y. The key property: for each x, ONE and only ONE y.

🎯 Try It: Feed The Machine

Input x
4
→
Rule f(x)
2x + 3
→
Output f(x)
11
f(4) = 2(4) + 3 = 8 + 3 = 11
xf(x) = 2x + 3

🧠 Big Ideas

The vertical line test: a graph is a function if no vertical line crosses it more than once. (Each x has one y.)
Linear vs. nonlinear: f(x) = 2x + 3 is LINEAR (constant rate, straight line). f(x) = x² is NONLINEAR (rate changes, curved).
Function notation f(x) reads as "f of x". f(4) means "plug 4 in for x."
