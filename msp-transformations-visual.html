🔄 Transformations — Slide, Flip, Turn, Resize

Four ways to move a shape while keeping (or changing) its size.

Four transformations: Translation (slide), Reflection (flip), Rotation (turn), Dilation (resize). The first three keep the shape's size — dilation changes it.

🎯 Try It: Pick A Transformation

🧠 Big Ideas

Rigid transformations (translate, reflect, rotate) preserve shape AND size — image is CONGRUENT to preimage.
Dilation changes size by scale factor k. Image is SIMILAR (same shape, different size). k > 1 = bigger, 0 < k < 1 = smaller.
Notation: preimage vertices A, B, C become A', B', C' after transformation (read "A prime").
