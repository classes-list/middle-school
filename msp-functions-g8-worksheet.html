1️⃣ What Is a Function?

A function assigns EXACTLY ONE output to each input. Like a machine: input → output.
Vertical Line Test: if any vertical line crosses the graph more than once, it's NOT a function.

Practice:

  1. Is (1,2), (2,4), (3,6) a function?
  2. Is (1,2), (1,3), (2,4) a function? Why not?
  3. Is a parabola y = x² a function?
  4. Is a sideways parabola x = y² a function?

Answer Key — Section 1

(1) Yes (2) No — input 1 has two outputs (3) Yes (4) No

3️⃣ Linear vs. Nonlinear

LINEAR = graph is a straight line, equation form y = mx + b. NONLINEAR = curve.

Practice:

  1. y = 3x + 5. Linear or nonlinear?
  2. y = x² − 2. Linear or nonlinear?
  3. y = 1/x. Linear or nonlinear?
  4. y = -x + 4. Linear or nonlinear?

Answer Key — Section 3

(1) Linear (2) Nonlinear (parabola) (3) Nonlinear (hyperbola) (4) Linear

4️⃣ Tables and Functions

In a table, if any input has two different outputs, it's not a function.

Practice:

  1. Table (1,2),(2,4),(3,6). Function?
  2. Table (1,2),(2,4),(2,5). Function?
  3. Table (1,3),(2,3),(3,3). Function? Linear?

Answer Key — Section 4

(1) Yes (2) No (input 2 has 2 outputs) (3) Yes; linear (horizontal line y=3)

5️⃣ Compare Functions Across Representations

A function can be shown as an equation, a table, a graph, or a verbal description. To compare two functions, first extract the same information from each representation, then compare.
CCSS 8.F.2 says: Compare properties of two functions each represented in a different way (algebraically, graphically, numerically in tables, or by verbal descriptions).

Usually you compare SLOPE (rate of change) and/or Y-INTERCEPT (starting value).

Toolkit — extract slope and y-intercept from each representation:

Given as…Get slope (m)Get y-intercept (b)
Equation y = mx + bcoefficient of xconstant term
Table(y₂ − y₁) / (x₂ − x₁)y-value when x = 0
Graphrise / run between two clear pointswhere line crosses y-axis
Verbal ("charges $5 plus $2 per mile")the "per" rate (per mile, per hour)the "starting" or "flat" amount

Practice — compare the two functions:

  1. Function A: y = 3x + 2. Function B: Table (0,5), (1,8), (2,11). Which has the greater slope? Which has the greater y-intercept?
  2. Function A: y = 2x + 6. Function B: A cab charges $10 plus $1 per mile. Which has the greater rate of change?
  3. Function A: Table (0,4), (1,6), (2,8). Function B: A line through (0,7) with slope 3. Which has the greater rate of change? Greater starting value?
  4. Function A: y = 5x. Function B: "A pool fills at 3 gallons per minute starting empty." Which fills/grows faster?
  5. Function A: Passes through (0,10) and (5,20). Function B: y = 3x + 8. Which has greater slope? Greater y-intercept?
  6. Function A: y = 4x + 1. Function B: "Sam saves $2/week starting with $10." Which grows faster? Which starts higher?
  7. Function A: Table (1,3), (2,5), (3,7). Function B: y = 2x + 4. Which is greater when x = 5?
  8. Function A: "A car starts at 100 miles and travels 60 mph away." Function B: y = 80x + 50. Which has greater rate? Greater starting value?

Answer Key — Section 5

(1) A: slope 3, b = 2. B: slope (8−5)/(1−0) = 3, b = 5. Same slope; B has greater y-intercept (5 > 2).

(2) A: slope 2. B: slope 1 (per mile). A has greater rate of change.

(3) A: slope (6−4)/(1−0) = 2, b = 4. B: slope 3, b = 7. B greater rate AND greater starting value.

(4) A: rate 5 (per unit x). B: rate 3 gal/min. A grows faster.

(5) A: slope (20−10)/(5−0) = 2, b = 10. B: slope 3, b = 8. B greater slope; A greater y-intercept.

(6) A: slope 4, b = 1. B: slope 2, b = 10. A grows faster; B starts higher.

(7) A at x=5: slope = (5−3)/(2−1) = 2, b = 1 → y = 2(5)+1 = 11. B at x=5: y = 2(5)+4 = 14. B greater at x = 5.

(8) A: rate 60, start 100. B: rate 80, start 50. B greater rate; A greater starting value.
