🏗️ Contractor Bid Showdown

Your family wants a new deck. Two contractors send bids. Which is cheaper for how big?

🎯 The Situation

Your family is planning to build a new deck in the backyard. Two contractors have sent bids:

Contractor A (BuildRight): $500 permit & setup fee, then $40 per square foot
Contractor B (DeckMaster): $1,500 permit & setup fee, then $25 per square foot

Question: At what deck size do both contractors charge the same? Which is cheaper for a small deck vs. a big deck?
🔨 Contractor A — BuildRight
  • Permit & setup fee: $500 (paid up front)
  • Per square foot: $40
Equation: try to figure it out ↓
🏗️ Contractor B — DeckMaster
  • Permit & setup fee: $1,500 (paid up front)
  • Per square foot: $25
Equation: try to figure it out ↓

1️⃣ Set Up the Equations

Write each bid as y = mx + b, where y = total cost and x = deck size in square feet.

🔨 Contractor A (BuildRight)

$ per sq ft of deck
$ paid before building
Permit & setup = b (y-intercept) because you owe it even if the deck is 0 sq ft — it's a fixed cost that doesn't depend on size.

Per sq ft = m (slope) because it's the rate the total goes up for each additional square foot built.

🏗️ Contractor B (DeckMaster)

$ per sq ft
$ up front

2️⃣ See the Graph

🎯 BuildRight starts LOWER but rises FASTER. DeckMaster starts higher but rises slower. The point where they cross is the "break-even" deck size.

3️⃣ Find the Break-Even Deck Size

Set the two bids equal to each other: 40x + 500 = 25x + 1500. Solve for x.

Start:   40x + 500 = 25x + 1500
Subtract 25x from both sides:   x + 500 = 1500
Subtract 500 from both sides:   15x =
Divide by 15:   x = sq ft
x ≈ 66.67 sq ft is the break-even deck size.
   BuildRight: 40(66.67) + 500 = 2,667 + 500 = $3,167 ✓
   DeckMaster: 25(66.67) + 1,500 = 1,667 + 1,500 = $3,167 ✓

  • Smaller than ~67 sq ft → BuildRight is cheaper (their lower setup fee matters more)
  • Exactly ~67 sq ft → Tied at about $3,167
  • Bigger than ~67 sq ft → DeckMaster is cheaper (their lower per-sq-ft rate saves you $15 per sq ft, adding up fast)

4️⃣ Make the Right Hire

Job A: A small 50 sq ft deck extension. Who's cheaper?

Job B: A big 200 sq ft family-size deck. Who's cheaper?

Job C: A 500 sq ft massive backyard project. Who's cheaper, and by how much?

Compute the savings: BuildRight = 40(500) + 500 = $20,500. DeckMaster = 25(500) + 1,500 = $14,000. DeckMaster saves $6,500!

🎓 What You Learned

Almost every "setup fee + per-unit cost" contractor bid is a linear equation. The setup fee is b (fixed cost, doesn't depend on size). The per-unit rate is m (grows with size).

The break-even size tells homeowners exactly which contractor is smarter for their specific project. This same math applies to plumbing quotes, roofing bids, electrician estimates, and even lawyer or accountant fees.
