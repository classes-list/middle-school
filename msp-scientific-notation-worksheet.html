1️⃣ Powers of 10

A "power of 10" means how many times you multiply 10 by itself. 10n tells you how many places to move the decimal. Positive n → big number; negative n → small number.

⚠️ Watch out with negative exponents! A negative power of 10 means the reciprocal:

10−n = 1 ÷ 10n = 1/10n

So 10−2 = 1/102 = 1/100 = 0.01 (not something you get by "moving the decimal left from 10.0").

Trick that works: to find 10−n, start from 1.0 (NOT 10.0) and move the decimal left n places.

Pattern: Each time the exponent increases by 1, the number gets 10 times larger (one more zero, or the decimal moves one place right). Each time the exponent decreases by 1, the number gets 10 times smaller (the decimal moves one place left).

2️⃣ Converting: Standard Form ↔ Scientific Notation

Scientific notation writes a number as a × 10n where 1 ≤ |a| < 10 and n is an integer. Move the decimal so only ONE non-zero digit is to the left. Count the moves — that's n. Move left → n positive. Move right → n negative.

💡 How to type scientific notation: use e as shorthand for "× 10^". For example, type 3e2 for 3 × 10², or 5.2e-4 for 5.2 × 10⁻⁴. You can also type 3*10^2 or 3 x 10^2.

5️⃣ Scientific Notation — Multiplication & Division

Now put the pieces together. The "a" part follows the sign rules from Section 3. The "10n" part uses exponent rules:

Discovery questions — write a full sentence:

  1. Why must the "a" part of scientific notation satisfy 1 ≤ |a| < 10?
  2. What would go wrong if we let a = 12 or a = 0.3?
  3. Why must n be an integer (whole number, positive or negative)?
  4. How does scientific notation make it EASIER to compare two very large or two very small numbers than standard form?

Answer Key — Section 6 (Discovery)

Try 1: Both display as 1,200,000 (or 1.2E+06). Yes, equal.

Try 2: Both give 3,000 (or 3E+03). Yes, equal.

Try 3: 7.224E+24 · 5,000 (or 5E+03).

Try 4: Yes — all three give 500,000. Only 5 × 105 is true scientific notation.

Discovery answers:

(1) The rule 1 ≤ |a| < 10 makes scientific notation unique — every number has exactly one correct way to write it, so numbers can be compared and ordered cleanly.

(2) If a = 12 (or a = 0.3), the same number could be written many ways (12 × 104 = 1.2 × 105 = 0.12 × 106), which defeats the purpose of a standard form.

(3) n must be an integer because it counts the number of decimal-place shifts. You can't move a decimal 2.5 places.

(4) Comparing 3.2 × 1012 to 4.7 × 1010 is instant — look at exponents first, then coefficients. Comparing 3,200,000,000,000 to 47,000,000,000 requires counting digits.
