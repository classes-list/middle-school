1️⃣ Composition

2️⃣ Inverses of Linear Functions

Swap x and y, then solve for y.

Practice:

  1. f(x) = 4x + 5. Find f⁻¹(9).
  2. f(x) = −4x − 9. The inverse is f⁻¹(x) = mx + c. What is m? (decimal ok)
  3. f(x) = −2x. Find f⁻¹(10).
  4. f(x) = 0.5x − 6. The inverse is f⁻¹(x) = mx + c. What is m? (decimal ok)
—

Answer Key — Section 2

3️⃣ Restricted Domains & Other Inverses

Practice:

  2. f(x) = x³ + 2. Find f⁻¹(3).
  3. f(x) = √x + 3 (x ≥ 0). Find f⁻¹(6).
  4. f(x) = √x + 2 (x ≥ 0). Find f⁻¹(7).

4️⃣ Verifying Inverses

f(g(x)) = x both ways; points swap.

Practice:

  1. Are f(x) = 4x − 3 and g(x) = (x − 3)/4 inverses? (yes or no)
  2. The point (-3, 7) is on the graph of f. What point must be on the graph of f⁻¹? (write as (x, y))
  3. Are f(x) = 2x + 7 and g(x) = (x + 7)/2 inverses? (yes or no)
  4. The point (-5, 0) is on the graph of f. What point must be on the graph of f⁻¹? (write as (x, y))
—

Answer Key — Section 4

(1) no (2) (7, -3) (3) no (4) (0, -5)
