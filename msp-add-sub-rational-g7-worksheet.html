1️⃣ Sign Rules: Add/Subtract

Same signs → add and keep sign. Different signs → subtract smaller from larger and keep sign of larger absolute value. Subtracting a negative = adding a positive.

Practice:

  1. 5 + 3 =
  2. -5 + 3 =
  3. 5 + (-3) =
  4. -5 + (-3) =
  5. 5 - (-3) =
  6. -5 - 3 =
  7. -7 - (-2) =
—

Answer Key — Section 1

(1) 8 (2) -2 (3) 2 (4) -8 (5) 8 (6) -8 (7) -5

2️⃣ Number Line Model

Positives move right, negatives move left. Subtracting a negative moves right.

Practice:

  1. Start at 3, add -5. End at?
  2. Start at -2, subtract -6. End at?
  3. (-4) + 7 on a number line =
—

Answer Key — Section 2

(1) -2 (2) 4 (3) 3
