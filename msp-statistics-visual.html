How to read it: The whiskers reach the smallest and largest values. The box covers the middle half of the data (Q1 to Q3). The line inside the box is the median. A long box or whisker means the data there is spread out.

🧠 Big Ideas

Outliers pull the MEAN. One giant value can drag the mean up (or down) far from where most data sits. The MEDIAN is safer for skewed data.
Mode tells you what's most common — great for shoe sizes, favorite colors, most-repeated grade.
Box plots show the spread in quarters. The IQR (middle 50%) ignores extreme values, so an outlier changes the range a lot but the IQR only a little. Try the "Outlier warning" data!
Range tells you how spread out the data is. Small range = tightly clustered. Big range = data all over the place.
