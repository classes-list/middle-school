4️⃣ Piecewise Functions

Check the condition first, then use that rule.

Practice:

  1. f(x) = 3x − 3 if x < −2; f(x) = x² − 4 if x ≥ −2. Find f(−2).
  2. f(x) = −x + 3 if x < −1; f(x) = x² + 4 if x ≥ −1. Find f(−1).
  3. f(x) = −2x − 3 if x < 1; f(x) = x² + 2 if x ≥ 1. Find f(2).
  4. f(x) = 3 if x < 1; f(x) = −x² + 3 if x ≥ 1. Find f(1).
