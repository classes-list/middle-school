📘 How It Works

Key idea: Make the pieces meet.

A function is continuous at a if f(a) exists, the limit exists, and they are equal. For a piecewise function, make the left piece and right piece give the same value at the break point, then solve for the unknown constant.

👀 Watch Two Examples

✏️ Worked Example 1
f(x) = x² + 2 for x < 3, and kx for x ≥ 3. What value of k makes f continuous? (decimal ok)
Answer: 3.6667
✏️ Worked Example 2
f(x) = x² − 2 for x < 4, and kx for x ≥ 4. What value of k makes f continuous? (decimal ok)
Answer: 3.5
