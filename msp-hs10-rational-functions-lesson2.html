📘 How It Works

Key idea: Denominator = 0 → vertical asymptote.

Vertical asymptotes are at x-values that make the denominator zero (after canceling any common factors). Factor the denominator and set each factor to zero.

👀 Watch Two Examples

✏️ Worked Example 1
Find the vertical asymptote of y = 6/(x − 5). Give x = ?
Answer: 5
✏️ Worked Example 2
Find the vertical asymptote of y = 6/(x − 0). Give x = ?
Answer: 0
