🏈 Fantasy Football Draft

Two players. Different starting points. Different scoring rates. Who scores more by season's end?

🎯 The Situation

It's week 3 of the fantasy football season. You're about to make a trade for a new player. You have two options:

Player A (veteran): Already has 20 fantasy points this season. Averages 8 points per game going forward.
Player B (rookie): Started slow — 0 points so far. But has been averaging 12 points per game in preseason.

Question: After how many more games will Player B catch up to Player A? Will B still be better by week 17?
🏈 Player A (Veteran)
  • Points already scored: 20
  • Average per game: 8 pts/game

🚀 Player B (Rookie)
  • Points already scored: 0
  • Average per game: 12 pts/game

1️⃣ Set Up the Equations

Write each player's total points as y = mx + b, where y = total season points and x = number of additional games played.

head start / starting value
Points already scored = the y-intercept b because that's their total before any more games (x = 0). It's their head start.

Pts per game = the slope m because it's the rate their total grows each game.

2️⃣ See the Graph

🎯 Notice: Player A's line starts HIGHER (20 pt head start) but rises SLOWER. Player B starts at 0 but rises FASTER. Where they cross is when B catches up.

3️⃣ Find the Break-Even Point

When are their totals equal? Set the equations equal: 8x + 20 = 12x + 0

Start:   8x + 20 = 12x
Subtract 8x from both sides:   20 = x
Divide both sides by 4:   x = games
x = 5 games is the tipping point.
   Player A after 5 more games: 8(5) + 20 = 60 points ✓
   Player B after 5 more games: 12(5) + 0 = 60 points ✓

  • Fewer than 5 more games → Player A is winning (his head start still matters)
  • Exactly 5 games → Tie
  • More than 5 games → Player B is winning (his faster scoring caught up)
There are 14 more games in the season. Player B will lead by 4 × (14 − 5) = 36 more points!

🎓 What You Learned

Every "current stats + future rate" problem is y = mx + b in disguise. The y-intercept b is your head start. The slope m is your rate of growth. When two lines have different starts AND different slopes, they always cross — and that crossing tells you WHEN a faster-growing option overtakes a leader.

This is the same math for: race pacing, career stats, college savings, book reading progress, fitness goals, and comeback wins.
