1️⃣ Mean Value Theorem

Average slope = instantaneous slope somewhere.

Practice:

  1. f(x) = x² + 5x + 5 on [−4, −3]. Find the value c guaranteed by the Mean Value Theorem.
  2. f(x) = −2x³ − x² + x on [−1, 1]. By the MVT, f′(c) must equal what number for some c?
  3. f(x) = −x² + 3x − 1 on [2, 7]. Find the value c guaranteed by the Mean Value Theorem.
  4. f(x) = 3x³ − x² + x − 3 on [−3, −2]. By the MVT, f′(c) must equal what number for some c?

2️⃣ Rolle’s Theorem

Equal endpoints → a horizontal tangent.

Practice:

  1. f(x) = (x − 1)(x − 4) satisfies Rolle’s Theorem on [1, 4]. Find c where f′(c) = 0.
  2. f(x) = (x + 4)(x − 5) satisfies Rolle’s Theorem on [−4, 5]. Find c where f′(c) = 0.
  3. f(x) = (x + 1)(x + 3) satisfies Rolle’s Theorem on [−3, −1]. Find c where f′(c) = 0.
  4. f(x) = (x − 3)(x − 5) satisfies Rolle’s Theorem on [3, 5]. Find c where f′(c) = 0.
