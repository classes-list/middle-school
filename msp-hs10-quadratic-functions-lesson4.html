📘 How It Works

Key idea: Set each factor equal to zero.

If the quadratic is factored, a(x − r)(x − s), the zeros are r and s — set each factor to zero. If it is not factored, try factoring first (find two numbers that multiply to ac and add to b), or use the quadratic formula.

👀 Watch Two Examples

✏️ Worked Example 1
Find the larger zero of y = −(x − 4)(x − 5).
Answer: 5
✏️ Worked Example 2
Find the smaller zero of y = x² + x − 6 (hint: factor).
Answer: -3
