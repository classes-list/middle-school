⚖️ The Balance Point — See a Weighted Average

Heavier weights pull the average toward them.

The visual truth: Put each value on a number line and stack blocks on it — more blocks for more weight. The weighted average is the balance point of the beam. A plain average treats every value the same; a weighted average lets the important values pull harder.

🧠 Big Ideas

The formula: Weighted average = (value₁ × weight₁ + value₂ × weight₂ + …) ÷ (weight₁ + weight₂ + …). If the weights are percents that add to 100%, just multiply by the decimals and add.
Always between: A weighted average always lands between the smallest and largest values — closer to the value with the most weight.
Chemistry connection: Atomic masses on the periodic table (like 35.45 for chlorine) are weighted averages of the isotopes, using how common each isotope is as the weight. That is why they are not whole numbers.
Common mistake: Averaging the values and ignoring the weights. Press Equal Weights to see when the two averages match — and change one weight to see them split apart.
