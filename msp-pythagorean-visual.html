📐 a² + b² = c² — See The Squares Add Up

The theorem isn't about lengths. It's about the AREAS of the squares on each side.

The visual truth: For any right triangle, the square built on the hypotenuse has the SAME area as the two squares on the legs, added together. Change the legs — watch the squares change size — the equation always balances.

🎯 Try It: Set The Legs, Watch The Squares

🧠 Big Ideas

Pythagorean Triples: Some triangles have all-integer sides — like 3-4-5, 5-12-13, 6-8-10, 8-15-17, 7-24-25, 9-40-41. Memorize these; they show up EVERYWHERE on tests.
Finding c: c = √(a² + b²). Always TAKE THE SQUARE ROOT at the end — a common mistake is stopping at c² and forgetting the last step.
Finding a missing leg: Rearrange to a² = c² − b². Then a = √(c² − b²). The hypotenuse is always the LONGEST side and always OPPOSITE the right angle.
