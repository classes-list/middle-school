📘 How It Works

Key idea: Each factor gives a zero.

If p(x) = (x − r₁)(x − r₂)…, each factor gives a zero: set it equal to zero. A factor like (2x − 3) gives x = 3/2. Sum or count the zeros as the question asks.

👀 Watch Two Examples

✏️ Worked Example 1
What is the smallest zero of y = (x + 4)(x + 3)(x + 1)?
Answer: -4
✏️ Worked Example 2
What is the smallest zero of y = (x + 2)(x + 1)(x − 5)?
Answer: -2
