📘 How It Works

Key idea: Average slope = instantaneous slope somewhere.

Compute the average slope [f(b) − f(a)]/(b − a). Then set f′(c) equal to it and solve for c, keeping only c strictly between a and b. For a quadratic, c is always the midpoint (a + b)/2.
