📘 How It Works

Key idea: Count negative factors: even → +, odd → −.

You don’t need to multiply out to find the sign. Plug the x-value into each factor and just note whether each factor is + or −. An even number of negative factors → positive; an odd number → negative.

👀 Watch Two Examples

✏️ Worked Example 1
For f(x) = −(x + 1)(x − 2)(x − 5), is f(−7) positive or negative? (Use a sign chart — no need to multiply everything out.)
Answer: positive
✏️ Worked Example 2
How many integers x with −8 ≤ x ≤ 7 satisfy (x + 5)(x − 1)(x − 4) > 0?
Answer: 8
