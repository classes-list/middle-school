3️⃣ One-Sided Limits

Use the piece on that side.

Practice:

  1. f(x) = x − 3 for x < 2 and 2x + 3 for x ≥ 2. Find the limit as x → 2 from the left.
  2. f(x) = x + 1 for x < 1 and 2x + 0 for x ≥ 1. Find the limit as x → 1 from the left.
  3. f(x) = x + 3 for x < -1 and 2x − 3 for x ≥ -1. Find the limit as x → -1 from the right.
  4. f(x) = x − 3 for x < 3 and 2x + 1 for x ≥ 3. Find the limit as x → 3 from the right.
—
